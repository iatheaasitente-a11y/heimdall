# Sesiones de desarrollo - Heimdall

Esta carpeta centraliza el registro de trabajo por sesión.

## Objetivo

Mantener un historial claro de qué se hizo, qué se validó, qué problemas aparecieron y cuál es el siguiente paso.

## Regla de documentación

- Cada commit debe actualizar o crear su entrada en la sesión correspondiente.
- Si comienza una nueva jornada o bloque de trabajo, se crea un archivo nuevo con formato `YYYY-MM-DD.md`.
- Si el commit pertenece a una sesión ya abierta, se añade a esa sesión.
- Cada sesión debe registrar cambios, tests, problemas, decisiones y siguiente paso.
- Antes de abrir o actualizar un pull request, la sesión debe estar al día.

## Plantilla

```markdown
# Sesión — YYYY-MM-DD

## Objetivo

## Necesidad del proyecto

## Trabajo realizado

## Archivos creados o modificados

## Verificación

## Problemas y decisiones

## Estado al finalizar

## Commits

| Commit | Mensaje | Cambio principal |
|---|---|---|
```
