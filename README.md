# heimdall

Chatbot-agente en Python para citas, hábitos, objetivos y recordatorios (asistente personal) y, como extra, un módulo NBA. El modelo de lenguaje interpreta y explica; Python calcula; SQLite conserva los datos.

Estado: dominio, esquemas, base SQLite y todos los repositorios SQLite y los servicios de usuarios, agenda y recordatorios listos, 272 tests. Siguiente: servicios de hábitos y objetivos.

Documentación completa en [docs/README.md](docs/README.md).

Ejecutar: `python -m venv .venv`, `.venv\Scripts\Activate.ps1` (Windows) o `source .venv/bin/activate` (Linux/Mac), `pip install -r requirements.txt`, `pytest -q`.
